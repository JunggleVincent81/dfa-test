KENALI MESINNYA

Lima komponen. Satu alur yang pasti.

DFA (Deterministic Finite Automaton) adalah mesin dengan sejumlah state terbatas. Mesin membaca input satu simbol setiap langkah, mengikuti fungsi transisi yang sudah ditetapkan.

Q

Kumpulan state

Semua keadaan yang dimiliki mesin, misalnya {q0, q1}.

Σ

Alfabet

Simbol input yang diizinkan, misalnya {0, 1}. ε berarti string kosong, bukan simbol alfabet.

δ

Fungsi transisi

Pemetaan Q × Σ → Q. Setiap pasangan state dan simbol wajib memiliki tepat satu tujuan.

q₀

State awal

Tempat mesin mulai sebelum simbol pertama dibaca.

F

State penerima

Subset Q. Jika input selesai dan state terakhir berada di F, string diterima.

ε

String kosong

Tidak membaca simbol apa pun. Diterima tepat ketika state awal termasuk F.

Cara memakai laboratorium

  1. Pilih contoh atau buat mesin sendiri.
  2. Isi state dan alfabet, lalu lengkapi seluruh sel tabel transisi.
  3. Tentukan state awal dan penerima.
  4. Masukkan string. Jalankan seluruh proses atau telusuri satu langkah per klik.
  5. Periksa state terakhir dan alasan hasilnya.

Simulator ini memakai satu karakter Unicode per simbol alfabet. String tidak dipangkas: spasi pada input tetap dianggap simbol dan dinyatakan tidak valid jika tidak ada dalam alfabet.
